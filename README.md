# 🇪🇺 Migración y Economía en Europa: Visualización y Análisis Interactivo

## Descripción
La migración, junto con indicadores socioeconómicos clave como el **PIB**, la **población** y el **desempleo**, constituye uno de los fenómenos más influyentes en el panorama europeo y español. La correcta interpretación de estas métricas es fundamental para una política pública informada y un debate social constructivo.

Este proyecto presenta una **aplicación interactiva** diseñada como un **cuadro de mando (Dashboard)**. Su objetivo es centralizar y visualizar datos oficiales de **Eurostat** sobre:

* **Flujos de Inmigración**
* **Producto Interior Bruto (PIB)**
* **Tasa de Desempleo**
* **Evolución Demográfica (Población Total)**

El proyecto no solo facilita la **visualización clara** y la **interpretación de estadísticas**, sino que también aplica técnicas de **Machine Learning** para añadir una capa predictiva y de análisis avanzado.

---

## Objetivos principales
* Crear un **cuadro de mando interactivo** con datos actualizados de PIB, Desempleo, Población e Inmigración en España y Europa.
* Facilitar la **interpretación integrada** de estas variables socioeconómicas y migratorias mediante visualizaciones intuitivas.
* Implementar modelos de **Machine Learning** de **Regresión Lineal** para predecir tendencias.
* Desarrollar modelos de **Escenarios Sintéticos** para explorar el impacto de diferentes variables.
* Garantizar la **transparencia** y el **acceso directo a datos oficiales** de Eurostat.

---

## Plan de trabajo

### Fase 1 – Extracción y transformación
* Creación del repositorio en GitHub ✅
* **Extracción de datos en tiempo real de la API de Eurostat**, eliminando la necesidad de descargas locales.
* Limpieza, normalización y estructuración de los datos para su análisis.

### Fase 2 – Carga y primeras visualizaciones
* Carga de los datos finales.
* Implementación de visualizaciones básicas de PIB, Desempleo, Población e Inmigración.
* Estructuración inicial del cuadro de mando.

### Fase 3 – Machine Learning
* Desarrollo de un modelo de **Regresión Lineal** para la predicción de flujos migratorios y/o variables económicas.
* Aplicación de modelos de **Escenarios Sintéticos** para simular y visualizar posibles futuros basados en la variación de las variables de entrada (p. ej., ¿qué pasa con la inmigración si el desempleo baja un X%?).
* Evaluación y validación de los modelos predictivos.

### Fase 4 – Cuadro de mando final
* Integración de visualizaciones y resultados de Machine Learning en un **dashboard interactivo**.
* Inclusión de **filtros detallados** (por país, por año, por tipo de variable, etc.) para una exploración profunda.

### Fase 5 – Entrega
* Documentación técnica del proyecto y del uso de la API de Eurostat.
* Presentación de resultados, modelos de escenarios de uso y conclusiones.
